# Vikey AI: Future-Forward Solutions

Создай новый чистый сайт для Vikey AI с нуля. Это не исправление старого сайта, а полностью новый проект.

Используй приложенное фото как главный визуальный образ на первом экране и в разделе “Обо мне”.

Позиционирование:

Vikey AI — AI-решения для бизнеса, контента и автоматизации.

Главная идея:

Помогаю бизнесу и экспертам внедрять AI-инструменты в реальные задачи: контент, сайты, визуал, автоматизация, чат-боты и рабочие процессы.

Стиль:

современный, технологичный, уверенный, немного футуристичный, но не перегруженный.

Цвета: графитовый, тёмно-синий, фиолетовый, неон-бирюза, мягкие голубые световые акценты.

Атмосфера: нейросети, цифровая энергия, экспертность, спокойная сила, AI-будущее.

Важно:

Не использовать старый код, старые debug-скрипты, fallback-скрипты, PWA, service worker или старые технические решения.

Сайт должен быть чистым, лёгким и стабильно открываться на Android, iPhone и desktop.

Технические требования:

- React/Vite

- без PWA

- без service worker

- без debug-скриптов

- без тяжёлых анимаций на первом экране

- без обязательных backend/API-запросов при загрузке

- без AI-консультанта на первом этапе

- без внешних виджетов на первом этапе

- сначала нужна стабильная базовая мобильная версия

Не добавлять услуги:

- презентации

- помощь студентам

- разведка рынков

Основные услуги:

1. AI-инструменты для бизнеса

2. Сайты и лендинги с AI

3. Визуальный контент с AI

4. AI-консультанты и чат-боты

5. Автоматизация рабочих процессов

6. Упаковка проекта или услуги
